**Objective**
The weather application is designed to provide users with real-time weather updates for any city worldwide. By leveraging a weather API, the application displays essential weather information such as temperature, humidity, wind speed, and current conditions in a user-friendly and visually appealing format.

**Features**
i created web application into add some feturs :

City Search:
Users can input the name of a city to retrieve the current weather data.

Real-Time Weather Data:
The application fetches live weather information using the OpenWeatherMap API.

Dynamic Weather Icons:
Weather conditions are visually represented through dynamic icons that change based on the data (e.g., clouds, rain, clear sky).

Error Handling:
Displays an error message for invalid city names or when data is unavailable.

Responsive Design:
Ensures the application works seamlessly on different devices, including desktops and mobiles.

**How It Works**
The user enters a city name in the search input field and clicks the search button.
The application sends a request to the OpenWeatherMap API with the city name.
The API responds with the current weather details, which are displayed on the screen:
City Name
Temperature (°C)
Humidity (%)
Wind Speed (km/h)
Weather Condition Icon

If an invalid city name is entered, an error message appears, prompting the user to try again.
